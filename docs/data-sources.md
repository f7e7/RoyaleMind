## Dataset Details Reviewed

- `wty-yy/Clash-Royale-Detection-Dataset` README reports **4,654 slices / 154 categories**. It describes Labelme JSON per manually labeled frame, derived YOLO text, a 2.6 Hog deck-only card crop set, and a small elixir-value crop set. Its mini detection split is 1,816 train and 454 validation frames from one episode: nearby-frame leakage is likely. Repository reports approximately **601,220 KB**; do not download without a separate storage and rights review.
- `wty-yy/Clash-Royale-Dataset` reports a large collection of object slices/replay data, not a current comprehensive held-out screen dataset. GitHub reports approximately **1,945,152 KB**. MIT is declared for the repository; game footage rights and historical class coverage still require review.
- `SudhishNeel/clash-royale-detection` Hugging Face snapshot exposes **22.8k `crops` rows** and **39.9k `crops_predicted` rows**; visible viewer shows 171 class labels in `crops`, and the card describes YouTube-derived crop/track data. The license tag is `other`, not a clear grant. It is a crop-classification source, not a full-frame detection dataset.
- `chrisrca/clash-royale-tv-replays` reports **52,876 rows**. Hugging Face size API reported **24,214,915,389 bytes** of Parquet data; the card separately displays a larger figure, so transfer/storage size needs confirmation before any retrieval. Frames are dense and source-footage rights and split leakage are unresolved.
- Dataset sizes and counts above are source-reported, not independently recounted locally. No such dataset was downloaded, extracted, deduplicated, or included in the 13 MB local metadata footprint.

## Official API Limitations

The developer portal loads as an application shell. The documentation route redirects/requires authentication; unauthenticated inspection could not establish the current endpoint catalog, field schemas, rate limits, game version, or terms. A credentialed human must verify those details. RoyaleMind must not scrape around the login gate or commit an API token.

## Imported JSON Categories

Pinned files include card identity, evolution rows, localized card names, source card statistics, card-specific troop/building/spell tables, character/unit statistics, projectile statistics, arena metadata, game-mode metadata, battle timelines, building-evolution metadata, and projectile-evolution metadata. Raw snapshots are local and ignored by Git. Normalized records preserve full source-specific dictionaries so unsupported source fields are not discarded.

No arena geometry is inferred from descriptive/background assets. Source arena records may contain progression/background metadata but do not establish normalized board coordinates, towers, river/bridge boundaries, or deployment polygons.
